# Patterna SDKs

Client libraries and the API contract for [Patterna](https://patterna.orven.am), the recommendation engine that proves what it earns.

| Language | Install | Folder |
|---|---|---|
| TypeScript / JavaScript | `npm install @patterna/sdk` | [`typescript/`](typescript) |
| Go | `go get github.com/payam-h/patterna-sdk/go@latest` | [`go/`](go) |
| Python | `pip install patterna-sdk` | [`python/`](python) |

The OpenAPI contract and the events contract are in [`contracts/`](contracts). Documentation: https://patterna.orven.am/docs.

This repository is published from Patterna's main repository on every SDK release; open issues here, changes land upstream.
